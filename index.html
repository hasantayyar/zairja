What executes, and what is supplied?

The app calculates all chord selections and removals from a transcribed 73-letter tape, reads the indexed key poem, converts the recorded numeric values, and performs the final 24+23 transposition.

Eighteen emitted letters depend on reverse-table or surface values supplied by the account. Those values are marked as recorded. This app does not reconstruct all 7,095 table fields or infer a general rule for other questions.

For R1 the text repeats an alif already removed earlier. The replay preserves that reported result and marks the exception. The strict comparison instead emits the bāʾ reached by removing each selected letter once.

The initial table search is also recorded: three groups are traversed before the selected letter, giving 3 × 3 = 9. Its full traversal is not independently regenerated.
